## 🎯 About This Repo

This repo tracks how I'm learning DSA, structure by structure, pattern by pattern.

**My approach:**

1. **Understand the data structure first** — its core properties, basic
   operations, and where it's actually used, how it overcomes the issue with its similar data structure before touching any problems.
2. **Identify the common patterns** — most problems on a given structure
   cluster into a handful of recurring patterns. I map these out before
   solving.
3. **Learn the underlying method** — for each pattern, understand the
   well-defined algorithm or technique behind it: its basic flow, and
   *why* that pattern needs it and how it can be used for problems that follow a particular pattern.
4. **Solve each problem in three passes:**
   - **Brute force** — the naive approach first, no shortcuts.
   - **Apply the pattern** — rework the solution using the relevant
     pattern/algorithm.
   - **Compare complexity** — see exactly how time and space complexity
     improve between the two, arriving at the optimized solution.

Each problem entry in this repo reflects that process — not just a final
answer, but the reasoning that got there.
